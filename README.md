# We Are Navodayan Backend

Enterprise backend platform for the We Are Navodayan community ecosystem.

## Architecture

The backend follows a microservices architecture using Java, Spring Boot, REST APIs, PostgreSQL, Redis, Kafka, and AWS.

## Services

- API Gateway
- Auth Service
- User Service
- JNV Service
- Alumni Service
- Community Service
- Opportunity Service
- Mentorship Service
- Event Service
- Notification Service

## Technology

- Java 21
- Spring Boot
- Maven
- Spring Security
- PostgreSQL
- Redis
- Apache Kafka
- Docker
- AWS
